# Chicago Taxi Trip Analysis

Exploratory data analysis and hypothesis testing on Chicago taxi trip data, focused on company activity, neighborhood demand, and the effect of rainy Saturdays on travel duration to O'Hare Airport.

## Project Objective
Analyze Chicago taxi trip behavior to identify operational patterns and validate weather-related effects on trip duration.

## Dataset
- `moved_project_sql_result_01 (1).csv`
- `moved_project_sql_result_04 (1).csv`
- `moved_project_sql_result_07 (1).csv`

Main fields analyzed include taxi company activity, destination neighborhoods, trip timestamps/day-of-week, weather conditions, and trip duration for Loop-O'Hare routes.

## Analysis Scope
- Taxi company activity analysis (trip volume by operator)
- Destination demand analysis (most frequent drop-off neighborhoods)
- Exploratory analysis of Loop to O'Hare trips
- Statistical hypothesis testing for rainy Saturdays vs. trip duration

## Business Questions Answered
- Which taxi companies show the highest activity levels?
- Which neighborhoods receive the highest volume of drop-offs?
- Do rainy Saturdays significantly affect trip duration to O'Hare Airport?

## Key Findings
- Taxi activity is concentrated among top operators, showing an uneven market distribution.
- Destination demand is concentrated in a subset of neighborhoods, including key transport hubs.
- Hypothesis testing supports that rainy Saturday conditions are associated with longer Loop-to-O'Hare trip duration.

## How to Use
1. Clone the repository.
2. Open `notebook (16).ipynb` in Jupyter Notebook or VS Code.
3. Run all cells to reproduce the exploratory analysis and hypothesis test results.
4. Review the final conclusions section for business interpretation.
